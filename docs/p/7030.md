## 2026/11/16（泰坦大战）

### 一、19级大本营

19级大本营采用深色外壳与金属装饰，是首个支持驻扎部队的大本营。详细数据请移步：[大本营升级数据](/upgrade/town-hall)。

### 二、大本营驻军与四种形态

- 19本的大本营可由玩家选择部队驻扎，被攻击时驻军会出来防守。
- 共有四种形态：**原始外观**、**野蛮人大本营**、**弓箭手大本营**、**法师大本营**。
- 所有玩家默认拥有野蛮人大本营。

- **弓箭手升到15级**解锁弓箭手大本营，**法师升到15级**解锁法师大本营。
- 驻军按玩家已研究的兵种等级出战；弓箭手与法师固定为15级（解锁条件即满级）。
- **每套阵型可独立保存选择**，不同阵型可以用不同驻军。
- 个人资料页显示主阵型的驻军，游戏其他地方一律显示原始外观。
- 原始外观不驻扎任何部队。
- 敌军进攻大本营时，驻军出战。

### 三、小队

小队是固定的部队组合，可一键部署；与逐一部署相比，能以相同所需空间部署更多部队。

- **8本起解锁**，需要建造并升级**小队训练营**。
- 小队训练营共12级，8本到19本每个大本等级开放1级，每级解锁一支小队。
- 小队成员的等级等于玩家已研究的兵种等级；未解锁的兵种以1级参战。
- 小队按固定阵型部署并带内置延迟，例如女巫戈仑小队先部署戈仑石人，稍后部署女巫。
- **小队升级是19本专属**，低级大本营部署的小队固定为1级。
- 小队在2级时获得技能，共6种：溅射抗性、隐密开场、陷阱感知、护盾开场、集火攻击、火冒三丈。
- 小队无法作为增援捐出。

### 四、守卫神殿

- 守卫不再驻扎在大本营，改为独立的**守卫神殿**。
- 守卫神殿**免费放置，无需建造时间**。
- [粉碎者](/upgrade/smasher)是18本推出的防守专用守卫，原本绑定大本营，本次更新后移入守卫神殿。
- 守卫的升级在守卫神殿中进行，本次开放**粉碎者10级**上限。
- 可在守卫神殿中选择由哪名守卫参与防守。

### 五、尖刺塔

尖刺塔（Spiky Tower）是一种**范围自动启动、受击即反击**的防御建筑：敌方部队进入11格范围内，经过1秒旋转蓄力便会启动。

- 启动期间，近战攻击、远程投射物、溅射伤害都会触发尖刺反击（摧毁它的最后一下命中不会触发反击）。
- 法术伤害和英雄装备**不会**触发反击。
- 冰冻不会阻止尖刺塔反击。

### 六、烟花炮手塔

烟花炮手塔（Firecracker Tower，繁体中文版写作「烟火射手塔」）由**满级箭塔（21级）和满级投石炮（7级）合并**而成。

- 可攻击地面和空中目标。
- 命中后向周围喷出火花，对附近目标造成溅射伤害。

### 七、英勇法术

英勇法术（Heroic Spell）在法术工厂升到10级后解锁（17本）。1、2级在17本，3级需18本实验室，4级需19本实验室。

- 区域内的地面部队**可以直接穿过城墙**。
- 与狂暴法术、急速法术**不叠加**。

### 八、魔法零食

魔法零食（Magic Snacks）是新的消耗品，可在战斗中使用。

| **零食**           | **效果**                                                       |
| -------------- | -------------------------------------------------------------------|
| 战斗糕点       | 家乡村庄战斗或排位战中获得的金币、圣水和暗黑重油成倍增加，分1倍、2倍、3倍 |
| 资源车棒棒糖   | 接下来3辆资源车中的战利品变为3倍（每次收集消耗1次，仍受仓库上限限制），仅可在家乡使用  |
| 部落城堡蛋糕块 | 使用后自动补满部落城堡增援，且接下来的3场家乡村庄战斗或排位战自动免费提供增援 |
| 星星饼干       | 额外提供一次每日胜利之星奖励，48小时内有效                                |

### 九、胜利之星重做

- 胜利之星奖励不再与排位联赛挂钩，改为**按大本等级决定**，同本玩家奖励相同。
- 联赛奖励（League Bonus）仍按排位段位计算，与胜利之星是两套独立体系。
- 收集**2颗星**可获得**2星零食包**；收集**5颗星**可获得完整胜利之星奖励和**5星零食包**。
- 每日刷新，未完成的进度会保留。

### 十、表情与荣誉商店

- **表情（Emotes）**每个系列包含5款表情：4款普通表情和1款奖励表情。收集系列中的前4款表情即可解锁奖励表情。
- 表情可在胜利界面、回放和聊天中使用。
- 部分表情为**情境表情**，会在满足触发条件时自动发送。
- **荣誉商店（Prestige Shop）**：每赛季结束时，排位奖杯结算为**排位战奖章**。
- 玩家可使用获取的游戏内货币，如排位战奖章、联赛奖章和电涌灵石，即可兑换表情、英雄装备、魔法物品、专属装扮、装饰等商品。
- 排位战奖章的持有上限由大本营等级决定。

### 十一、全服聊天

- **友谊战**：可在全服聊天发起挑战，第一次进攻后挑战仍然开放，并附带排行榜。
- 友谊战仅限家乡，在夜世界或都城时会提示返回家乡。
- **精彩时刻分页**：可集中查看群组内的友谊战回放。
- **分享**：可分享回放、阵型和配兵。
- **设备端翻译**：翻译在设备上完成，文本不会发送到外部。
- **Supercell ID 好友**：三处好友列表合并为一处。
- 好友关系由服务器校验，仅好友可用的操作无法伪造。

### 附：国服差异

国际服与国服的核心玩法一致，但部分系统按运营方不同：

- 国服有**黄金令牌激活卡**（可赠送他人）、委托系统、繁荣度、公共频道。
- 国际服有**表情**、**荣誉商店**、**Supercell ID 好友**。
- 升级时间的缩短幅度以游戏内数据为准。
